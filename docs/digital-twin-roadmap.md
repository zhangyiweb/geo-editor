# 数字孪生地形能力规划

> 面向 **Three.js 数字孪生**（发电厂、园区、港口、矿山等）场景。  
> 现有能力：地名/经纬度定位 → 框选 → DEM 挤压 → 多源卫星贴图（含局部精度）→ GLB / KTX2 / STL 导出。  
> 本文说明「还缺什么、为什么缺、建议落地顺序」。

---

## 1. 背景与目标

数字孪生里的地形不是「好看的山」，而是：

- 厂房、管廊、道路、设备模型的 **空间基准面**
- 与测绘/总图/GIS 数据对齐的 **真实地理参考**
- 可被业务逻辑查询的 **高度与碰撞数据**

本编辑器输出应能直接进 Three.js 场景，并满足：**对得上、摆得准、接得进、跑得动**。

---

## 2. 现状能力（已具备）

| 能力 | 说明 |
|------|------|
| 选区 | 矩形 / 圆形；主区域 + 局部精度区 |
| DEM | AWS Terrarium 高度网格，可调 zoom / 网格上限 / 垂直夸张 |
| 贴图 | Esri / USGS / Bing / OSM / Mapbox；整区与局部 zoom |
| 预览 | 二维选区 + 三维小窗 / 全屏 |
| 导出 | GLB 一体、GLB+KTX2 分包、STL、仅贴图 |

已落地：

- **真实海拔**：顶点 Y = 海拔米 × 垂直夸张（默认夸张=1）
- **`{stamp}.meta.json`**：原点、轴向、范围、高程写入导出包
- **加载示例**：`examples/threejs-load/loadTerrainPack.ts`
- **项目存档**：面板「保存项目 / 打开项目」JSON

仍缺（相对孪生生产需求）：

- DEM / 影像依赖 **公网公开源**，精度与商用版权不足
- 选区仅矩形/圆，难贴合厂界
- 高度查询 API、分块 LOD 等（见下文）

---

## 3. 高优先级（对接孪生必踩）

### 3.1 坐标系元数据一起导出（`terrain.meta.json`） ✅ 已落地

导出 GLB / 分包 ZIP 时附带 `{stamp}.meta.json`（原点经纬度、轴向 X东/Y上/Z南、范围米数、真实高程、夸张系数等）。

**用途**：孪生里用同一原点把地形与管线、建筑、GPS 轨迹对齐。

---

### 3.2 绝对高程（真实海拔） ✅ 已落地

顶点 `Y = elevMeters × verticalExaggeration`（默认夸张=1）。预览网格贴在最低海拔面。

**用途**：与图纸标高、管线埋深、构筑物竖向对齐。

---

### 3.3 自定义 DEM / 正射上传

**做什么**

支持导入：

- 测绘 / 无人机 **GeoTIFF DEM** 或灰度高度图  
- 厂区 **正射影像**（Ortho）覆盖公网卫星图  

**用途**

公开 DEM（如 Terrarium）分辨率粗、更新慢；电厂常有厘米～米级测绘。自定义数据才能做出「能对总图」的厂区地形，也规避公网影像商用版权风险。

---

### 3.4 多边形厂区裁切

**做什么**

除矩形/圆外，支持导入 **GeoJSON / KML / CAD 厂界**，按任意多边形裁切网格与贴图。

**用途**

厂区边界不规则。矩形会带进大量厂外废面；按厂界裁切后模型更干净，也方便与总平面图、红线叠合。

---

### 3.5 工程侧加载 SDK / 示例 ✅ 已落地（基础版）

见 `examples/threejs-load/`：`loadTerrainPack`、`lngLatToLocal`、README。

**用途**：业务仓库复制加载逻辑，按 meta 挂贴图与摆模型。

---

## 4. 中优先级（大场景与业务逻辑）

### 4.1 分块 / LOD

**用途**  
厂区几公里时，单块高精网格易卡。按瓦片或四叉树分块，近高远低，保证帧率。

### 4.2 高度查询 API

**用途**  
`(x, z) → y`、射线采样：设备自动贴地、车辆行驶、管线敷设、碰撞检测都依赖「任意点地面高度」。

### 4.3 项目存档（JSON） ✅ 已落地

面板「保存项目 / 打开项目」：选区、局部精度、面板参数、地图视野。打开后需重新生成地形网格。

**用途**：同一厂区可复现生成参数，避免「上次怎么切的忘了」。

### 4.4 网格简化 + 法线 / 置换图

**用途**  
低模跑流畅，细节靠法线/置换贴图，适合大屏巡检与 Web 端孪生。

### 4.5 水体 / 平坦填方

**用途**  
水库、冷却池、平整 dig 区在电厂/园区极常见；需要在 DEM 上局部拉平或挖湖，而不是只靠卫星图「看起来像水」。

---

## 5. 低优先级（体验、表现与合规）

| 项 | 用途 |
|----|------|
| 矢量压平（路、围墙、河） | 矢量线贴地，增强可读性与路径示意 |
| 材质分层 / Splat | 草地、硬化场地、水面分区着色，更接近实景孪生 |
| 离线瓦片 / 版权策略 | 内网部署、商用授权合规 |
| 测量工具 | 两点距离、坡度、粗算土方，服务方案汇报 |

---

## 6. 建议落地顺序

```text
1. terrain.meta.json 坐标系
2. 绝对高程开关
3. 自定义 DEM / 正射
4. 厂界多边形裁切
5. 加载 SDK + 示例
────── 以上完成后，基础孪生对接闭环 ──────
6. 高度查询 API
7. 项目存档
8. 分块 / LOD
9. 简化与法线贴图
10. 水体 / 填方与其它表现项
```

---

## 7. 成功标准（验收视角）

完成高优先级后，应能做到：

1. 导出包在 Three.js 中加载，原点与 meta 一致  
2. 厂房模型按经纬度或本地坐标落到正确位置与标高  
3. 可用测绘 DEM + 正射替换公网数据  
4. 地形外形贴合厂界，无明显厂外废面  
5. 新项目按示例文档 1 天内完成接入，而不是反复对坐标
