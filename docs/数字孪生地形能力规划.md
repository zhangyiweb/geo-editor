# 数字孪生地形能力规划

> 面向 **Three.js 数字孪生**（发电厂、园区、港口、矿山等）场景。  
> 现有能力：定位选区 → DEM 真实海拔 → 卫星贴图 → meta / 项目存档 / 可运行 GLB 预览包。  
> 本文只列 **尚未落地** 的能力、用途与建议顺序。

---

## 1. 背景与目标

数字孪生里的地形不是「好看的山」，而是：

- 厂房、管廊、道路、设备模型的 **空间基准面**
- 与测绘/总图/GIS 数据对齐的 **真实地理参考**
- 可被业务逻辑查询的 **高度与碰撞数据**

输出应满足：**对得上、摆得准、接得进、跑得动**。

---

## 2. 高优先级

### 2.1 自定义 DEM / 正射上传

支持导入测绘 / 无人机 **GeoTIFF DEM**（或灰度高度图），以及厂区 **正射影像** 覆盖公网卫星图。

**用途**：公开 DEM 粗、更新慢且有版权限制；电厂常有厘米～米级测绘，才能对总图、可商用。

### 2.2 多边形厂区裁切

除矩形/圆外，支持导入 **GeoJSON / KML / CAD 厂界**，按任意多边形裁切网格与贴图。

**用途**：厂界不规则时去掉厂外废面，方便与总平面、红线叠合。

---

## 3. 中优先级

### 3.1 分块 / LOD

厂区几公里时单块高精网格易卡。按瓦片或四叉树分块，近高远低，保证帧率。

### 3.2 高度查询 API

`(x, z) → y`、射线采样：设备贴地、车辆、管线敷设、碰撞都依赖「任意点地面高度」。

### 3.3 网格简化 + 法线 / 置换图

低模跑流畅，细节靠法线/置换贴图，适合大屏巡检与 Web 端孪生。

### 3.4 水体 / 平坦填方

水库、冷却池、平整 dig 区：在 DEM 上局部拉平或挖湖，而不是只靠卫星图「看起来像水」。

---

## 4. 低优先级

| 项 | 用途 |
|----|------|
| 矢量压平（路、围墙、河） | 矢量线贴地，增强可读性与路径示意 |
| 材质分层 / Splat | 草地、硬化场地、水面分区着色 |
| 离线瓦片 / 版权策略 | 内网部署、商用授权合规 |
| 测量工具 | 两点距离、坡度、粗算土方 |

---

## 5. 建议落地顺序

```text
1. 自定义 DEM / 正射
2. 厂界多边形裁切
3. 高度查询 API
4. 分块 / LOD
5. 简化与法线贴图
6. 水体 / 填方与其它表现项
```

---

## 6. 成功标准（验收视角）

完成高优先级后，应能做到：

1. 可用测绘 DEM + 正射替换公网数据  
2. 地形外形贴合厂界，无明显厂外废面  
3. 业务侧能查询地面高度并稳定摆放设备  

---

## 7. 相关命令

```bash
npm run dev        # 本地编辑器
npm run build      # 生产构建
```
